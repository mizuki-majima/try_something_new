# 0004. Gate 5 の独立レビューの指摘を D1〜D13 の決定で直す

- Status: Accepted（D12 は個人情報に当たるので CEO 確認待ち）
- Date: 2026-10-07
- Decider: AI PM

## Context

Gate 5（REVIEW → TEST、[#2](https://github.com/mizuki-majima/try_something_new/issues/2)）の独立レビューと、その指摘を反証しようとした検証で、次が確かめられた。

- **Critical**: バックアップの読み込み（`POST /api/me/import`）に回数・件数の上限が無く、作成の規則も通らない。匿名アカウント1つで「今月の組」を200件の宣伝で埋められ（CUF-3 が壊れる）、書き込み費用にも上限が無い
- **High**: 公開カード（`/s/:id`）を通報する手段が無い（FR-18 違反）
- Medium / Low: 非表示にしたカードの画像が公開されたまま、IPv6 で IP ごとの上限が効かない、使い捨てアカウント3つで何でも隠せる、origin-verify の入れ替えで数分 API が止まり送信待ちが捨てられる、PILOT の指標がチャレンジ単位、API のエラーのアラームがルートの 500 を見ていない、予算が共用アカウント全体を見ている、など

テスト用の環境（`https://d1zw3n37kpuo7t.cloudfront.net`）は誰でも開ける状態なので、PILOT の前に直す。

## Decision

| | 決定 | 選ばなかった案 |
|---|---|---|
| D1 | 読み込みは1人1日3回・1回100件・1人合計200件・開いているもの5件まで。作成・印・振り返りと同じ規則で整え、本人が書き込むまで1日組と PILOT の指標に出さない | 読み込み自体をやめる（端末を失くしたときの復旧手段が無くなる） |
| D2 | 非表示のカード画像は `hidden/share/` へ移し、CloudFront は `share/` だけを配る。画像のキャッシュは5分 | 画像を API 経由で配る（Lambda の呼び出しと費用が増える）、削除のたびに CloudFront を無効化する（荒らしに使われると費用になる） |
| D3 | 止めたカードを本人が作り直して公開できない（403） | — |
| D4 | 作成の開始日は今日の7日前〜翌日と次の1日 | 端末側で開始日を今日に書き換える（押した印の日がずれる） |
| D5 | PILOT の指標は人単位（validation-plan の定義どおり） | — |
| D6 | IP キーは HMAC-SHA256（鍵は SSM `/thirty-days/ip-hash-key`）、IPv6 は /64 | IPv6 を止める（利用者の回線によっては遅くなる） |
| D7 | 自動非表示に数える通報は、作成24時間以上・チャレンジを持つアカウントからだけ | しきい値を上げる（本当の通報でも隠れにくくなる） |
| D8 | API は origin-verify を複数受け付け、CloudFront が送る値は別のパラメータ。3回のデプロイで入れ替える | ヘッダの確認をやめる（API Gateway を直接呼べてしまう） |
| D9 | リマインドはイベントの予定時刻で枠を決め、15分より古いイベントは捨てる | — |
| D10 | `/s/:id` に「このカードを通報する」（お問い合わせ画面の通報フォームへ） | `/s/:id` にフォームを置く（スクリプトもフォームも無いページの CSP を緩めることになる） |
| D11 | 重複のない人数でなければ「人」と表示しない | — |
| D12 | お問い合わせの返信先（任意）は残し、返信にだけ使って180日で消す。プライバシーポリシーをそれに合わせる | 返信先の欄をなくす（返信できない） |
| D13 | 開始・投稿の前に同意の一文、全画面にフッター | — |

詳細は [SPEC.md](../../SPEC.md) v1.1（本文に D 番号）、運用は [docs/deploy.md](../deploy.md)。

## Consequences

- 既存の環境は、更新の前に `node scripts/setup-secrets.mjs` を1回実行する（`ip-hash-key` と `origin-verify-send` を作る）。`npm run deploy` は `--check` でこれを確かめる
- 予算は費用配分タグ `Project` を有効にするまで $0 のまま。それまではアカウント全体の予算アラートが頼り
- 画像保存・SNS での共有は人に結びつかないので、PILOT の共有率は公開リンクを作った人だけで数える（低めに出る）
- **CEO に確認すること**: D12（お問い合わせの返信先として個人情報を180日持つ）。`status:needs-ceo` の Issue で Option A（いまのまま）/ B（欄をなくす）と推奨（A）を示す
- 見直す条件: PILOT で通報や読み込みの上限に当たって困る人が出たら、上限を見直す
