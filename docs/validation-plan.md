# Pilot Plan — 30日だけ

Owner: AI PM ／ 作成: 2026-10-06 ／ 更新: 2026-10-07（計測の方法を追記。合格ラインは変えていない）／ Status: **Approved**（2026-10-07 CEO が PILOT 開始を承認。[ADR 0005](decisions/0005-pilot-approval.md)）

> 趣味のサービスのため、支払意思の検証は行わない（[ADR 0001](decisions/0001-hobby-service-skip-payment-validation.md)）。代わりに PILOT で「使われるか」を測る。合格・停止の基準は **実施前に** 決め、結果を見てから変えない。

## 仮説

| # | 仮説 | 検証方法 |
|---|---|---|
| H1 課題 | 新しいことを試したいが、1人だと途中で消えてしまう | 参加者への開始時・終了時の一言アンケート |
| H2 価値 | 30日で区切る・印を押す・同じ月の仲間が見えることで、最後まで試せる | 完走率（30日目に振り返った人の割合） |
| H3 口コミ | 振り返りカードを共有したくなる | 振り返った人のうち、カードを共有した割合 |

## 対象と人数

CEO の友人・同僚 10人前後。CEO が直接声をかける（AI は連絡しない）。

## 方法

1. 公開 URL を CEO が共有する
2. 翌月1日に「1日組」として一斉スタート（最初の1日組は **2026-11-01**、30日目は 2026-11-30）
3. 30日後に振り返り。管理画面の統計で数値を見る

## 指標と判定基準（実施前に固定）

| 指標 | 定義 | 合格ライン |
|---|---|---|
| 開始数 | 期間中にチャレンジを始めた人 | 8人以上 |
| 7日継続 | 7日目までに印を5個以上押した人 ÷ 開始した人 | 60%以上 |
| 完走 | 30日目（または7日目以降の区切り）に振り返った人 ÷ 開始した人 | 40%以上 |
| 共有 | 振り返りカードを共有（公開リンク・画像保存・SNS）した人 ÷ 振り返った人 | 30%以上 |

計測は管理画面の統計（SPEC FR-18。2026-10-07 の AI PM 決定 D5 で人単位にそろえた）。どれも**人の数**で、1人が複数のチャレンジを持っていても1人と数える。その時点で残っているチャレンジから数え、バックアップから読み込んだだけのチャレンジは数えない。

| 指標 | 管理画面の値 |
|---|---|
| 開始数 | `starters`（開始日が来たチャレンジを持つ人） |
| 7日継続 | `retained7` ÷ `eligible7`（最初に始めたチャレンジが8日目以降になった人のうち、1〜7日目に印5個以上のチャレンジを持つ人） |
| 完走 | `reflected` ÷ `starters`（振り返り済みのチャレンジを持つ人） |
| 共有 | `sharers` ÷ `reflected`（振り返り済みで公開リンクがいまある人）。画像保存・SNS 共有は匿名の回数しか取らない（人に結びつけない）ので人数には入らず、回数を参考に見る。そのため共有率は実際より低めに出る |

計測の注意（基準は変えない。Gate 7 では次も並べて報告する）:

- 管理画面は 1日組に限らず全員を数える。参加者以外の利用や11月の途中から始めた人が混ざるので、**招待した人数**（非公開の pilot-log に記録）と `starters` を並べる
- 7日継続の分母は管理画面では `eligible7`（最初のチャレンジが8日目以降になった人）。判定時（12月）には1日組の全員が含まれる

- **CONTINUE**: 完走 40%以上、かつ 2つ以上の指標が合格
- **PIVOT 候補**: 開始は 8人以上だが、7日継続が 30%未満
- **PAUSE 候補**: 開始が 5人未満（届いていない）

## 期間と予算

- 期間: 公開から最初の1日組の30日目まで
- 予算: AWS 月 $1 未満の見込み（$10 超でメール。2026-10-07 に設定: [#6](https://github.com/mizuki-majima/try_something_new/issues/6)）。AI は使わない

## 法令・倫理

利用規約・プライバシーポリシーを公開してから人を招く。アカウントのためのメールアドレスなどの個人情報は集めない（お問い合わせに任意で書かれた返信先だけは、返信のためだけに使い180日で消す。D12、2026-10-07 CEO 承認）。

## 記録

数値は管理画面の統計。参加者の名前・感想など個人に関わる記録は非公開の ai-product-org/services/try-something-new/ に置く。

## CEO 承認が必要な事項

- 本番公開（URL を人に配ること）
- 月 $10 を超える費用
